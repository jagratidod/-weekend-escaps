# -weekend-escaps

> Premium Himalayan Adventure & Trekking Platform built with React, Vite, Node.js, Express, MongoDB Atlas, Cloudinary CDN, and Tailwind CSS.

## 🏔️ Features

- **Dynamic Booking & Expedition Catalog**: High-altitude snow treks (Kedarkantha, Kashmir Valley, Manali, Spiti Valley, Bali).
- **Interactive Gallery & Staggered Showcases**: Smooth Framer Motion animations, Lightbox preview, and authentic Himalayan photo archive.
- **Verified Traveler Stories & Testimonials**: User reviews with live photo upload and real-time moderation approval workflow.
- **Admin Dashboard**: Manage bookings, packages, hero banners, and moderate traveler reviews.
- **Cloudinary CDN Integration**: High-performance optimized cloud image delivery and direct memory buffer uploads.
- **Secure Authentication**: JWT-based authentication with role-based access control (Admin & User).

## 🚀 Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion, Lucide React, Swiper
- **Backend**: Node.js, Express.js, MongoDB Atlas (Mongoose)
- **Cloud Storage**: Cloudinary SDK
- **Security**: Helmet, CORS, Express Rate Limit, JWT, BcryptJS

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/jagratidod/-weekend-escaps.git
cd -weekend-escaps
```

### 2. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
